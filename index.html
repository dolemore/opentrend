    About OpenTrend

    OpenTrend is MobileClaw's open-source trend dashboard. Every section is fed by an hourly-refreshed snapshot of GitHub's trending page, the HuggingFace Hub API and GitHub's repository search — so what you see is what developers are star-ing this hour.

    The curated collections come from our research notebook: dozens of repositories across AI agents, LLM inference, video generation, Android tooling, self-hosted SaaS alternatives, web scraping and WiFi sensing projects.

    Pick a language from the menu above — the whole page ships pre-translated in twelve languages, with brand names kept intact.

    Data sources

    • github.com/trending — daily & weekly trending
    • huggingface.co — trendingScore API
    • GitHub Search API — curated metadata
    • GitHub Actions — hourly data refresh
